学习率一大，
为什么就飞出去？

拖动参数，亲手把一个点推下抛物线。你会看到：学习率不是「越大越快」；超过 1，它会在谷底两侧越跳越远。

01 / 先押一个答案

η = 1.2，会发生什么？

预测目标函数是 f(x) = (x − 2)²，从 x = 0 出发，学习率 η = 1.2。每一步都按梯度下降走，轨迹会怎样？
把误差记作 e = x − 2。梯度是 2(x − 2)，更新后：
e′ = (1 − 2η)e。代入 η = 1.2，得到 e′ = −1.4e。
绝对值 1.4 > 1，所以误差不会缩小，反而每步变成 1.4 倍，并且左右换边。

03 / 拆开看

稳定边界为什么是 1？

现象目标在 x = 2。真正决定「会不会收敛」的，不是 x 本身，而是误差 e = x − 2。
关键f′(x) = 2(x − 2)，所以更新是 x′ = x − 2η(x − 2)。两边同时减 2，得到 e′ = (1 − 2η)e。
计算要让误差每步缩小，必须有 |1 − 2η| < 1；解出来就是 0 < η < 1。η = 0.8 时因子是 −0.6：每步缩到 60%，并换到另一侧。
反例η = 1.2 时因子是 −1.4，绝对值大于 1。这不是「走得更快」，而是每一步都把误差放大 40%；不踩刹车，很快就飞出画面。

这就是「学习率不是越大越好」的数学原因：它乘在梯度上，也乘在了误差的放大倍数上。山谷越陡（曲率越大），能承受的步长越小。

行话拆解：梯度下降。梯度指向当前位置上升最快的方向；梯度下降就朝反方向走一小步。学习率决定这一小步有多长。步长太小，收敛慢；步长太大，直接跨过谷底，甚至越跨越远。

换一座更陡的山谷

如果 f(x) = 5(x − 2)²，梯度变成 10(x − 2)，误差因子是 1 − 10η。稳定条件 |1 − 10η| < 1 就变成 0 < η < 0.2——同样是二次函数，山谷陡了 5 倍，允许的学习率就小了 5 倍。

边界说明：这是一个二次函数的「显微镜」实验，用来看清步长与曲率的关系。真实神经网络是非凸的，还常用随机梯度、动量、Adam 等机制；这里的 η < 1 不是通用公式，而是让你先看懂「为什么会冲过头」。

04 / 迁移

换一座山谷，你还会判断吗？

迁移题把目标函数换成 f(x) = 5(x − 2)²，仍然从 x = 0 出发。学习率 η 在什么范围内，梯度下降会收敛到 x = 2？
更新式：x′ = x − η · 10(x − 2)，误差 e′ = (1 − 10η)e。
收敛要求 |1 − 10η| < 1，即 −1 < 1 − 10η < 1，解得 0 < η < 0.2。
直观理解：山谷陡 5 倍，同样的步长会把你推得更远，所以必须把步长缩到原来的 1/5。
反馈类型：客观校验。轨迹、f(x)、误差与「下一跳」都由 x′ = x − η·2(x−2) 实时计算；没有预设动画。曲线只画到 x ∈ [−1, 5]，飞出视野时会在边缘标出方向。
