第 1 站 · 卡点

两个特征量级差 100 倍，地形就变成一条细沟

你已经会调学习率了。但同样一个学习率，在这份数据上很好，换一份就得调到极小 —— 为什么？

「特征缩放」把每个特征换算到差不多的范围（比如都除以标准差）。不改变信息，只改变地形形状。

就像把「米」和「厘米」统一成一种单位再一起算。

「细长沟」一个方向很陡、一个方向很平的地形。梯度下降只能在里面来回折返，走得极慢。

就像一条又窄又长的山谷，你没法斜着走，只能左右横跳着往前进。

现象一个特征范围 0~1，另一个 0~10000。训练时损失下降得又慢又抖。
为什么量级大的特征稍微动一点就让预测变很多，所以在误差面上是陡方向；量级小的是平方向。陡方向限制住学习率上限，平方向就又慢得离谱。
所以于是把特征缩放到相近尺度，地形从细长沟变成接近圆的碗，一个学习率就能同时照顾两个方向，几十步就到底。
不这样假如不缩放、只把学习率调到极小来避免震荡，平的方向几乎不动 —— 训练不报错，但模型基本没学到东西。这种「安静地失败」更难发现。

第 2 站 · 自测

先答，答完才看解释

反馈类型：客观校验（每题有唯一正确答案，选完立刻判定）。 第 3 题是迁移题 —— 换一个没在这节课出现过的新情境。

1. 两个特征量级差 100 倍，误差面的形状最可能是？

一个方向曲率大、一个方向曲率小，等高线被拉成细长椭圆。梯度下降在这种形状上会锯齿式前进，很慢。
只有两个方向曲率相同时才接近圆。
二次型损失在这种情况下的形状是确定的椭圆。
损失是二维函数，不会退化成直线。

2. 缩放特征之后，最优的模型预测会变吗？

缩放是线性变换，预测能力不变；但同一个特征现在的系数要相应放大或缩小才能表达同样的关系。所以「参数变了」不代表「模型变差了」。
不会变差，只是参数换了标尺。
参数数值会变，因为输入尺度变了。
可以确定：这是同一族解的重参数化。

3. 迁移：只做标准化（减均值除标准差），但数据里有个极端离群点，会出什么问题？

标准化用的均值和标准差都对离群点敏感。一个 500 的离群点会把标准差拉得很大，正常点全挤在 0 附近。这时该用中位数和四分位距（鲁棒缩放）。
均值和标准差都会被离群点严重影响。
不会自动删。
不会报错，是「安静地变差」。
第 3 站 · 动手

亲眼看见细长沟让梯度下降变慢

// E(x,y) = x^2 + 100*y^2  —— y 方向陡 10 倍，就是细长沟
const grad = (x, y) => [2 * x, 200 * y];
const lr = 0.009;            // 受陡方向限制，只能取这么小

let [x, y] = [1, 1];
for (let i = 1; i <= 60; i++) {
  const [gx, gy] = grad(x, y);
  x -= lr * gx; y -= lr * gy;
  if (i % 20 === 0) console.log(`i=${i} x=${x.toFixed(4)} y=${y.toFixed(4)}`);
}
预期输出
i=20 x=0.4482 y=0.1493 i=40 x=0.2009 y=0.0056 i=60 x=0.0900 y=0.0001
已运行。x 从 1 降到 0.09 花了 60 步，而 y 早就几乎到 0 —— 同一个学习率，两个方向速度差几十倍，这就是细长沟。
