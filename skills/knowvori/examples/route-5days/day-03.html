第 1 站 · 卡点

步子多大算太大，是可以算出来的

你知道「学习率太大会发散」，但「太大」是多大？靠一次次试？

「振荡」在最优值两侧来回跳，但不跑远。误差不再下降，也不爆炸。

就像钟摆被推过了头，在两边来回晃。

「发散」误差不是越来越小而是越来越大，最后变成 NaN 或 Infinity。

就像下山时越走越往山上跑。

现象学习率调大一点收敛变快；再大开始振荡；再大直接发散。
为什么对 E(k)=(k−k*)² 这种碗形，每走一步，离最优的距离就乘以 |1 − 2·学习率|。这个因子小于 1 就收敛，等于 1 就原地弹跳，大于 1 就发散。
所以于是「太大是多大」有了答案：学习率 0.5 时因子为 0，一步到位；超过 1 就开始发散。真实问题阈值不同，但道理一样。
不这样假如不管三七二十一设成 1.0 求「一步到位」，那在稍微复杂的误差面上会立刻发散 —— 0.5 这个最优值只对最简单的碗形成立。

第 2 站 · 自测

先答，答完才看解释

反馈类型：客观校验（每题有唯一正确答案，选完立刻判定）。 第 3 题是迁移题 —— 换一个没在这节课出现过的新情境。

1. E(k)=(k−3)²，学习率 0.5，从 k=0 出发，第一步到哪？

梯度 2×(0−3)=−6，k ← 0 − 0.5×(−6) = 3。正好到最低点，因为因子 |1−2×0.5|=0。
再算一遍：−0.5×(−6) 是 +3，不是 +1.5。
符号和数字都不对。
没有过头，正好落在 3。

2. 学习率取 1.2 会怎样？

因子 |1−2×1.2| = 1.4 > 1，每步距离乘 1.4，指数增长 → 发散。
超过 1 就发散了，不是更快。
因子大于 1 是发散；正好等于 1 才是稳定振荡（学习率 = 1）。
是逐步变大，若干步后才溢出，不是立刻。

3. 迁移：真实模型参数很多，误差面不是简单碗形。那「临界学习率」还查得到吗？

高维非凸面上没有简单公式。工程做法是从很小的值开始按倍数放大，看损失在哪个学习率开始变差，取小一点的那个。
只有极简单的二次型有闭式解。
随便设经常直接发散。
不会自动修正，除非专门写了调度策略。
第 3 站 · 动手

自己扫一遍临界学习率，别信我

const E = (k) => (k - 3) ** 2;
const grad = (k) => 2 * (k - 3);

for (const lr of [0.1, 0.9, 1.0, 1.05, 1.2]) {
  let k = 0;
  for (let i = 0; i < 30; i++) k = k - lr * grad(k);
  console.log(`lr=${lr.toFixed(2)}  k30=${k.toFixed(3)}  E=${E(k).toFixed(3)}`);
}
预期输出

已运行。注意 lr=1.0 既不收敛也不发散，在 0 和 6 之间永久弹跳（因子正好等于 1）。超过 1 就开始爆炸。
